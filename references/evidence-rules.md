## 1. 三类内容

- **事实**：访谈原话、观察记录、问卷结果、文件条款、公开数据。
- **解释**：研究者对事实之间关系的判断。
- **建议**：面向行动主体提出的下一步动作。

在笔记和初稿中显式标记三类内容，避免把企业观点写成客观事实，把研究者推测写成受访者结论，或用愿望替代效果证据。

## 2. 证据等级

| 等级 | 典型材料 | 使用方式 |
|---|---|---|
| A | 原始录音、原始问卷、现场记录、正式原文、可复核数据 | 可支撑核心事实，仍需检查口径与授权 |
| B | 经核对的转写、企业正式材料、政府或权威机构公开材料 | 可支撑事实与背景，重要数字尽量回到原文 |
| C | 新闻报道、二手汇编、单方陈述、未经充分交叉验证的案例 | 用作线索或有限佐证，避免单独支撑强结论 |
| D | 来源不明截图、AI生成内容、无法打开或无法核实的转述 | 不进入正式结论，只列为待确认 |

证据等级代表可核查性，不自动代表内容真实或结论成立。

## 3. 证据卡

本文件中的模板是本 Skill 唯一的证据卡规范。以「一个核心判断」为单位建卡，一个判断可以挂接多条证据；不要把整章只对应一张笼统证据卡。

```text
核心判断：
正文安全表述：

证据项 1：
- 来源：谁、何时、什么文件或记录
- 类型与等级：访谈、观察、问卷、正式文件或公开材料；A/B/C/D
- 定义与口径：指标、对象、时间、单位和分母
- 直接支持：该材料能够证明的最强结论
- 不能支持：仍需其他样本或验证的结论
- 授权状态：能否研究使用、录音、实名或公开，是否需要匿名

证据项 2：按需添加
反例、冲突或替代解释：
待补证与处理：补证、降级、删除或保留占位
```

存在多条证据时分别保留来源、口径和授权，不要合并成无法追溯的概括。正文安全表述必须与证据卡中的最强可支持结论一致。

## 4. 交叉验证

优先使用以下组合：

- 访谈 + 现场观察；
- 访谈 + 企业公开材料；
- 问卷 + 访谈解释；
- 政策原文 + 执行主体访谈；
- 单个案例 + 其他案例或反例；
- 地方材料 + 同类地区公开经验。

交叉验证不是追求所有材料完全一致。冲突本身可能暴露定义差异、执行落差或主体立场，应单独记录并解释。

## 5. 结论强度

| 已有证据 | 可以支持 | 不能直接支持 |
|---|---|---|
| 单次访谈 | 该受访者的经历或判断 | 企业整体、行业普遍情况 |
| 单个企业案例 | 该企业的路径和约束 | 同类企业必然如此 |
| 少量案例出现共同现象 | 样本内共同特征与初步假设 | 地区比例、全国规律 |
| 小规模便利问卷 | 受访样本倾向和线索 | 精确总体比例 |
| 政策文件 | 制度规定、目标和适用对象 | 实际执行效果 |
| 项目被采纳或试用 | 已发生采纳或试用 | 长期成效、经济收益 |

优先使用「在受访样本中」「案例显示」「初步判断」「材料共同指向」「仍需扩大样本验证」。

没有充分因果识别时，少用「导致、证明、决定」，改用「相关、影响、制约、可能解释、形成条件之一」。

## 6. 数字与图表

- 为每个数字保留来源、单位、时间、范围、分母和计算方法。
- 不把五个案例写成「80%企业」，也不把访谈频次伪装成行业比例。
- 样本过小或量表主观时，使用「高、中、待验证」或证据矩阵，不使用小数评分和权威评级措辞。
- 图表标题保持中性，在相邻正文中写结论、解读和限制。
- 每张图表都能回答一个问题；不能帮助推断结论的图表删除。

## 7. 授权与匿名

- 企业明确不公开的内容不得公开。
- 未获得实名公开授权时，匿名化企业、个人、订单、客户和敏感经营信息。
- 匿名处理不能改变事实含义，也不能用多个细节反向暴露身份。
- 区分「允许访谈」「允许录音」「允许研究使用」「允许实名公开」。
- 引用转写前回到原始录音或原文核对；无法核对时标为转述。
- 对小样本行业或社区调研，负面内容不得同时出现可识别业务标签与问题；数量使用「两家」「部分」「数家」等复数或模糊表述，不使用「某一家」；不得组合可定位的时间与业务细节。正面材料也要检查是否会反向锁定负面对象。
- 建立实名对象与授权登记：每个在正文、图表或附录中出现真名的主体均登记出现位置、支持材料、实名公开授权状态和待核对事项。未核销实名公开授权，不得进入终稿。

## 8. 外部资料

- 对政策、比赛规则、统计数据和时效性事实优先查找官方原文或权威一手来源。
- 记录页面标题、发布机构、发布日期、链接和访问日期。
- 二手文章可用于发现线索，正式结论尽量回到原始来源。
- 对规模较小、公开信息更新不稳定的主体，网络资料默认作为线索而非现状事实。涉及当前经营、转型或项目进展的事实必须有年份；无年份即为未核实。
- 网络资料与访谈对当前事实冲突时，回到原始访谈或其他一手材料核对，不得静默择一拼接。确认冲突源于时间、口径或主体视角差异时，将冲突本身作为发现记录，并据此限定结论。
- AI回答不是事实来源。AI只能协助检索、整理、比较和表达。
- 查不到时明确写「未核实」或删除，不补造看似合理的来源。

## 9. 成稿后事实抽查

在完整报告、全文重构或多章改稿完成后，逐条抽查承担论证功能的具体事实，包括数字、时间、因果性表述、受访者原话转述和现实状态判断。对每条事实记录：

- 正文位置与安全表述；
- 原始来源文件和可定位位置；
- 支持强度、时效和授权状态；
- 无法定位时的处理：降级、删除或标为待确认。

不能回到原始材料的事实不得继续承担核心论证功能。
